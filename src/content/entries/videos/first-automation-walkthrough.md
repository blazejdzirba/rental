## What this recording covers

1. Picking a process that is boring and frequent
2. Writing down the steps before touching code
3. Automating **one** step end-to-end
4. Leaving the rest manual on purpose

## Why start tiny

Big automation rewrites fail quietly. One reliable alert or one merged calendar teaches the loop: observe → script → schedule → forget.
