Awesome-lists are where good tools go to be forgotten. Here’s a short list I still type weekly:

1. **[ripgrep](https://github.com/BurntSushi/ripgrep)** — search that feels instant
2. **[fd](https://github.com/sharkdp/fd)** — find files without remembering `find` flags
3. **[jq](https://github.com/jqlang/jq)** — JSON without opening a browser
4. **[httpie](https://github.com/httpie/cli)** — human HTTP
5. **[just](https://github.com/casey/just)** — project commands without Makefile pain

Install them once. Your future self says thanks.
